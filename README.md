# 가짜 "해킹중" 터미널 애니메이터

## 실행 방법
1. 압축을 풀고 이 폴더로 이동
2. 의존성 설치
   ```
   npm install
   ```
3. 개발 서버 실행
   ```
   npm run dev
   ```
4. 터미널에 뜨는 주소(보통 http://localhost:5173)를 브라우저로 열기

## 구성
- `src/App.jsx` : 핵심 로직 — 랜덤 로그 생성, 타이핑 애니메이션, 진행바, "ACCESS GRANTED" 글리치 엔딩
- `src/App.css` : 비주얼 — 초록 톤 CRT 스타일, 스캔라인, 비네트, 글리치 효과

## 커스터마이징 포인트 (원하면 Claude Code에 요청)
- `LOG_GENERATORS` 배열에 로그 패턴 추가/수정
- 색상 톤 변경 (초록 → 앰버는 `App.css`의 색상 값을 `#ffb000` 계열로 교체)
- 타이핑 속도 조절 (`App.jsx`의 `sleep(10 + Math.random() * 20)` 값)
- 사이클 반복 없이 한 번만 실행하고 멈추게 하려면 `runSequence`의 `while` 루프 제거

## 릴스 캡처 가이드 (10~20초 기준)
1. 브라우저 창을 배경 없이 터미널만 보이도록 확대 (F11 전체화면 추천)
2. 로그가 몇 줄 쌓이고 진행바가 절반쯤 찬 시점부터 녹화 시작
3. "ACCESS GRANTED" 글리치 연출까지 포함해서 끊기 — 임팩트 있는 엔딩이 릴스 완주율에 도움됨
4. 필요하면 배속(1.2~1.5배)으로 살짝 당겨서 편집하면 리듬감이 더 좋아짐
